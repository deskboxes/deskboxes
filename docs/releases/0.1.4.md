## Highlights

This release teaches the sorting rules about **games**: Steam, Epic, GOG and other store games now have a type of their own, so they can go into a Games box while your Apps box keeps only apps. A new **shortcut target** rule sorts icons by where they lead, and Deskboxes is now **source-available** on GitHub, with its releases, issues and discussions in one place.

### 🎮 Games get their own box

Deskboxes now reads where each shortcut leads, so it can tell a game from an app. Two new types are available in sorting rules:

- **Games:** shortcuts that start a game from Steam, Epic Games, GOG Galaxy, Ubisoft Connect, EA app, Battle.net, Riot, Amazon Games, itch, Heroic and Playnite, plus shortcuts straight into a game's install folder (such as `steamapps\common`).
- **Game launchers:** the Steam, Epic Games, Battle.net, Xbox and other store apps themselves, as a separate type, so you choose which box they go in.

To set it up, right-click your Games box › **Box settings › Sorting › Put here automatically › Games**. A narrower rule now always goes ahead of a broader one, so a Games rule wins over a "Programs and shortcuts" rule without reordering anything by hand.

### 🧭 Sort by where a shortcut leads

A new rule kind, **Shortcut target**, matches the program, folder or web address a shortcut opens: *contains*, *starts with*, *ends with* or *is*. For example, `steamapps` catches every Steam game, and `youtube.com` every YouTube link. Find it in **Settings › Sorting rules**.

### 📂 Deskboxes is now on GitHub

The source code, releases, issues and discussions now live together at [deskboxes/deskboxes](https://github.com/deskboxes/deskboxes), under the [PolyForm Strict License](https://github.com/deskboxes/deskboxes/blob/main/LICENSE.md). Report bugs with the new issue forms, ask questions in Discussions, and report security issues privately. Installed copies follow the move by themselves.

### 🧩 Other notable changes

- **Make boxes:** "Sort now" with no rules (and a new install) now also makes a Games box when your desktop has games.
- **Web links:** the "Websites" type now covers only internet addresses (http and https). Other link files, such as a Steam game's, count as programs.

## Full release notes

### Performance

* Changed the icon snapshot format, so the first start after updating reads every icon again once

### Repository and Updates

* Moved the source code and the releases into one public repository, [deskboxes/deskboxes](https://github.com/deskboxes/deskboxes)
* Added bug report and feature request forms, Discussions, a contributing guide and a security policy
* Changed updates to come from the new repository; this version was also published to the old one, so earlier versions update to it as usual
* Updated the link to all release notes in **Settings › Updates**
* Improved the release notes in **Settings › Updates**: tables and pictures meant for the web page are left out

### Sorting Rules

* Added the **Games** type for store games and games' own install folders
* Added the **Game launchers** type for Steam, Epic Games, GOG Galaxy, Battle.net, Riot Client, Ubisoft Connect, EA app, Rockstar, Amazon Games, itch, Heroic, Playnite and the Xbox app
* Added the **Shortcut target** rule, with contains, starts with, ends with and is
* Added a Games box to **Make boxes**; game launchers go into it only when the desktop has games
* Changed **Websites** to cover only http and https links; other link files count as programs
* Improved rule order: a rule for a narrower type (Games, PDF, Word …) moves ahead of a rule for a broader one (Programs, Documents) when it is added or changed
* Fixed Steam and other game links being sorted as websites

### Known issues

* Xbox and Microsoft Store games can't be told apart from apps, except Minecraft. Use a **Shortcut target** or name rule for those.
* Shortcuts kept only in OneDrive (not downloaded) are not read, so they sort as before.
* Deskboxes still shows boxes on the main monitor only. Support for several monitors is in the works.
