## Highlights

Deskboxes **opens its menus sooner** and is **ready sooner after it starts**. Right-clicking the desktop shows its menu about five times faster, and Deskboxes **uses less memory** on large desktops and after Settings closes.

### 🖱️ Faster menus

- **Desktop:** right-clicking an empty spot on the desktop showed its menu in about 100 ms on our test PC; now it takes about 20 ms. The menu is prepared ahead, and again after each time you close it.
- **Icons:** the menu for the file type you have most of on your desktop is prepared when Deskboxes starts, so the first right-click on one of those icons doesn't wait.
- **Right-button selection:** when you draw a selection with the right mouse button, its menu is prepared while you draw.
- **After sleep or Settings:** the menu helper restarts in about a tenth of a second instead of more than a second, so a right-click right after waking the PC or closing Settings shows a menu.

### 🚀 Ready sooner after starting

- The menu helper starts as soon as your desktop is drawn: it was ready about 450 ms after start, and now about 150 ms.
- The list of app menu entries (from apps installed from the Store and elsewhere) is kept from one start to the next. Reading it took about 0.4 s; now it takes a few milliseconds, and it is still checked in the background.
- The first menu is fully ready about 0.4 s after start instead of 1.5 s.

### 🪶 Lighter

- **Large desktops:** with 2,000 icons, Deskboxes used about 199 MB; now about 148 MB.
- **Settings:** the memory Settings used is given back a minute after you close it (from 176 MB to 52 MB for the menu helper).
- **Recycle Bin:** a check that found nothing changed no longer redraws the desktop.

## Full release notes

### Context Menu

* Improved the desktop menu: it is prepared ahead and shows about five times faster
* Improved the first right-click on an icon: the menu for the desktop's most common file type is prepared at start
* Improved right-button selection: the selection's menu is prepared while you draw
* Improved the menu after sleep or after Settings closes: the menu helper restarts in about a tenth of a second
* Improved how soon menus work after Deskboxes starts: the menu helper starts as soon as the desktop is drawn
* Improved reading the list of app menu entries: it is kept between starts and checked in the background

### Desktop

* Fixed the desktop being redrawn after a Recycle Bin check that found nothing changed
* Improved start: the graphics device is set up while the desktop is read

### Performance

* Reduced memory use on desktops with many icons
* Reduced the menu helper's memory use a minute after Settings closes
* Changed the menu helper's log to start a new file at 2 MB

### Known issues

* At sign-in, the first picture of the desktop waits for the graphics driver to be ready, which can take up to about a second on some PCs.
