## Highlights

The first public release of **Deskboxes**, a desktop organizer for Windows 11. It keeps your desktop icons in **boxes** with **tabs** and **roll-up**, sorts new files with **sorting rules**, and comes with a Fluent **Settings** window and a per-user installer. Your files stay in the Desktop folder; Deskboxes only changes how their icons are shown.

### 📦 Boxes, tabs and roll-up

Group icons into boxes that you can move, resize and snap to the screen edges, each with its own color, transparency and background blur. A box can hold several tabs, and a box docked at a screen edge can roll up to its title and open when you point at it.

### 🧭 Sorting rules

New icons go into the right box by themselves: by file type, name, extension, age or size. **Sort now** tidies the whole desktop at once, and every change can be undone with Ctrl+Z.

### 🧩 Other notable changes

- **A–Z index:** keep a box in name order, with a letter bar for jumping to a letter.
- **Folder boxes:** show a folder's files in a box.
- **Boxes above windows:** bring the boxes up over open windows with a shortcut or a screen corner.
- **Search:** start typing on the desktop to find any icon.
- **Hide all, saved layouts, locks and privacy mode:** see the full notes below.

## Full release notes

### Boxes and Tabs

* Added boxes that can be moved, resized and snapped to screen edges and other boxes
* Added per-box color, transparency and background blur, following Windows' light and dark mode
* Added tabs, switched from the box's title bar
* Added automatic roll-up for boxes docked at a screen edge, opening on hover, click or double-click

### Desktop

* Added search: start typing on the desktop to find any icon
* Added **Hide all**: double-click an empty spot to show only the wallpaper
* Added locks that stop boxes and icons from being moved or resized by accident
* Added privacy mode, which hides icon names when someone is looking
* Added Windows' own right-click menus for icons and the desktop, with the commands other apps add, plus Deskboxes' own

### Folder Boxes

* Added folder boxes that show a folder's files in a box

### Layouts

* Added saved layouts, and daily backups of the last seven days

### Setup

* Added a per-user installer that needs no administrator rights, with autostart at sign-in
* Added a watchdog that restarts Deskboxes after a crash and brings Windows' own icons back if it can't
* Added `--restore-icons`, which brings Windows' own desktop icons back at any time

### Sorting Rules

* Added rules by file type, name, extension, age and size
* Added **Sort now** and the A–Z index

### Known issues

* Only the main monitor is supported.
* The installer is not code-signed, so Windows SmartScreen may warn when you run it.
