## Highlights

Deskboxes now **updates itself**. Installed copies check for a new version once a day, download it in the background and install it the next time Deskboxes starts. This release also fixes rolled-up boxes closing again right after a double-click.

### ⬆ Automatic updates

Once a day, Deskboxes looks for a newer version on GitHub. A newer installer is downloaded in the background, kept only if its size and SHA-256 hash match, and installed quietly the next time Deskboxes starts. **Settings › Updates** has the switch, **Check now** and **Install now**.

### 🧩 Other notable changes

- **Roll-up:** double-clicking a rolled-up box's title now keeps it open.
- **Settings:** pages appear in one smooth motion instead of card by card.

## Full release notes

### Boxes

* Fixed a double-click on a rolled-up box's title opening the box and rolling it up again straight away

### Settings

* Added **Settings › Updates** with automatic updates, **Check now** and **Install now**
* Improved page changes: each page fades in and rises as one piece, without a blink

### Setup and Updates

* Added a daily update check, background download with size and SHA-256 checks, and a quiet install at the next start
* Added `--update` to the installer, which keeps autostart and the Start menu shortcut as they were
