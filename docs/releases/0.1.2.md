## Highlights

This release makes Deskboxes handle files **like Explorer**: undo and redo for moves, deletes and renames, Explorer's own drag and drop, and dropping icons **between** others. Boxes get **their own views and icon sizes**, folder boxes get **tabs**, a new install **sorts your desktop into boxes**, and Settings has a picture and a short clip for every feature.

### 📂 Files, like in Explorer

Undo and redo (Ctrl+Z, Ctrl+Y) now cover moving icons into a folder, sending them to the Recycle Bin and renaming. Dragging works the way it does in Explorer: the icon follows the pointer, a caption says what will happen (**Move to Recycle Bin**, **Open with …**) and folders light up under it. Drop an icon between two others to put it right there; the others move aside while you drag.

### 🗂 Box views and sizes

Each box can have its own icon size and view: extra large to small icons, **List**, **Details** or **Tiles**. Hold Ctrl and scroll over a box to change it, or set all boxes at once from the desktop's **View** menu.

### 🧭 Boxes from the start

On a new install, your icons are sorted into boxes for apps, folders, documents, media, and installers & archives, as one step that Ctrl+Z takes back. With no rules yet, **Sort now** makes those boxes for you.

### 🧩 Other notable changes

- **Folder boxes:** show any folder you choose, change it later, and open folders in tabs.
- **Icon looks:** tint icons, or let them blend into the wallpaper until you point at them.
- **Settings:** new pages for Blend into wallpaper, Updates and About, and a picture and clip for every feature.
- **Speed:** dragging, selecting and boxes with many files are quicker, most of all on older PCs.

## Full release notes

### Boxes Above Windows

* Fixed the wallpaper turning black and part of a box showing under the taskbar

### Boxes and Tabs

* Added a view and icon size per box (extra large to small icons, List, Details, Tiles), changed with Ctrl+wheel
* Added **Icons in all boxes** to the desktop's View menu
* Changed a tab's color to color its whole box while that tab is open
* Changed a dropped box to push icons along their row or column instead of scattering them; they go back when it moves away
* Fixed the Details view's column names scrolling away with the rows

### Drag and Drop

* Added Explorer's drag image and captions ("Move to …", "Move to Recycle Bin", "Open with …"), and folder highlights under the pointer
* Added dropping icons between two others, on the desktop, in boxes and in folder boxes; the others move aside while you drag
* Added scrolling a box with the mouse wheel during a drag
* Added the right-button selection rectangle, which opens the selected icons' menu
* Changed a selection rectangle started on the desktop to go behind the boxes

### Files

* Added undo and redo for moving into folders, deleting to the Recycle Bin and renaming
* Added dropping files on the Recycle Bin to delete them; Shift+Delete asks first in Windows' own dialog
* Added new files and folders appearing where you right-clicked, ready to rename

### Folder Boxes

* Added choosing any folder for a folder box, and changing it later
* Added tabs in folder boxes ("Open in new tab")
* Added a custom order inside folder boxes, kept per folder

### Icons

* Added icon tint, which keeps each icon's light and shade
* Added **Blend into wallpaper**: icons and their names take the wallpaper's colors until you point at them

### Menus

* Changed the desktop menu to open where Windows' own would, and to close when you click into another app

### Performance

* Improved dragging, selecting and large boxes, most of all on older PCs
* Improved start at sign-in: Deskboxes starts right after you sign in, without Windows' usual startup delay
* Fixed wallpaper changes taking a while to show

### Settings

* Added pages for Blend into wallpaper, Updates and About
* Added a designed picture for every feature, with a short clip that plays when you point at it, and large on the feature's own page
* Fixed light and dark mode differences, including in file dialogs

### Sorting Rules

* Added sorting a new install's desktop into default boxes, as one undoable step
* Changed **Sort now** with no rules to make the default boxes
