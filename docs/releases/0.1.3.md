## Deskboxes 0.1.3

This release adds **Desktop pages** and makes Deskboxes faster at sign-in. It also gives the rename field and the Settings window a more native Windows 11 feel, and makes undo, setup and updates more reliable.

Installed copies update themselves. To install for the first time, download **DeskboxesSetup.exe** below and run it.

### New

- **Desktop pages.** You can have more desktops side by side, each with its own boxes and icons. Switch between pages in any of these ways:
  - Alt+Left / Alt+Right, or Alt+mouse wheel
  - A two-finger touchpad swipe
  - Dragging the desktop with the middle button or both buttons
  - Holding dragged icons or a box at the screen edge

  Pages slide over a still wallpaper, and the page's name shows briefly at the top of the screen. You can create, rename and delete pages from the desktop menu or in Settings › Desktop pages. "Move to page" sends icons or boxes to another page, and search finds icons on every page. Your files stay in the Desktop folder; pages only change where icons are shown.
- **Native rename field.** Renaming an icon now uses a Windows 11-style text field, placed exactly where the name was, that grows as you type. Windows' file name rules apply: the name length limit, and a tip when you type a character a name can't contain. Pasted text is cleaned up the same way.
- **Smoother icon motion.**
  - Dropped icons glide from where you let go into their place instead of jumping.
  - New icons fade in, for example a file you just created or a delete you undid.
  - When an icon leaves a box, the icons left in the box close the gap smoothly.

### Improved

- **Faster start at sign-in.** Deskboxes now loads the wallpaper in parallel with everything else, and appears only once its first frame is ready. The desktop no longer shows a gray area while Deskboxes starts.
- **Faster first scan.** Thumbnails and folder previews are now created in parallel. On a desktop with 1,000 items, the first scan takes 1.8 s instead of 4.7 s.
- **Settings.**
  - Pages change with the same motion as Windows Settings.
  - The feature clips are redrawn with Windows' motion curves.
  - Clips are encoded to play on more PCs.
  - Opening a feature page no longer flashes black before its clip starts.
- **Responsiveness with many icons.** Moving and resizing boxes, switching pages, saving the layout, drawing large boxes and opening the desktop menu all do less work.

### Fixed

- "Turn on Deskboxes" now appears in the main Windows 11 desktop menu, not only under "Show more options".
- Context menus keep working after Deskboxes is turned off and on again.
- With boxes above windows, icons can be dragged into apps, between boxes and onto the desktop.
- Right-dragging a selection rectangle inside a box now selects icons.
- **Undo and redo of file operations**
  - Undoing a copy, or redoing a delete, no longer recycles a different file that has since taken the same name.
  - Undoing a delete restores the exact version that was deleted.
  - An undo that fails completely no longer enables redo.
  - Quick successive file commands update the right history entry.
  - Undoing a deletion made on another page puts the icon back on its own page.
  - Undoing a layout change no longer hides files that arrived after it.
- **Setup and updates**
  - Reinstalling over an existing installation is safe, also when the folder path is spelled differently.
  - Setup only removes its own files and only closes its own programs.
  - An interrupted upgrade no longer leaves a partly overwritten installation.
  - A failed update download no longer discards an installer that was already downloaded and checked.
- **Your layout**
  - A layout saved by a newer version is kept, not overwritten.
  - A daily backup that fails no longer replaces a good one.
  - A brief failure to read the desktop no longer clears box assignments.
  - Desktop icons come back if graphics recovery fails after Explorer restarts.
- **Pages, sorting and search**
  - "Use for all boxes" and the icon view setting apply to boxes on every page.
  - "Move to page" respects locks.
  - Search finds files in folder boxes on other pages.
  - A sorting rule that targets a folder box no longer blocks later rules.
  - The first file on an empty desktop goes to the chosen page.
  - Short, fast touchpad swipes change pages reliably.
- **Other fixes**
  - The hot corner no longer triggers from a neighboring monitor.
  - Two hard links to the same file show as two icons.
  - Opening one folder that two folder boxes show only navigates the box you clicked.
  - Folder boxes stop watching folders you have left.
  - Images no longer used are released from memory.
