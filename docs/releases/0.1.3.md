## Highlights

This release adds **Desktop pages**: several desktops side by side, each with its own boxes and icons. Deskboxes also **starts faster** at sign-in, renames icons in a **native Windows 11 text field**, and makes undo, setup and updates more reliable.

### 🗂 Desktop pages

Keep more than one desktop, each with its own boxes and icons. Switch pages with Alt+Left / Alt+Right or Alt+mouse wheel, a two-finger touchpad swipe, dragging the desktop with the middle button, or by holding dragged icons or a box at the screen edge. Pages slide over a still wallpaper and show their name briefly at the top. Create, rename and delete pages from the desktop menu or in **Settings › Desktop pages**; **Move to page** sends icons or boxes to another page, and search finds icons on every page. Your files stay in the Desktop folder.

### ⚡ Faster start

Deskboxes loads the wallpaper alongside everything else and appears only once its first frame is ready, so the desktop no longer shows a gray area at sign-in. The first scan of a desktop with 1,000 items takes 1.8 s instead of 4.7 s.

### ✏ Native rename field

Renaming an icon uses a Windows 11-style text field, placed exactly where the name was, that grows as you type. Windows' file name rules apply, with a tip when you type a character a name can't contain.

### 🧩 Other notable changes

- **Motion:** dropped icons glide into place, new icons fade in, and boxes close the gap when an icon leaves.
- **Settings:** pages change with the same motion as Windows Settings, and the clips play on more PCs.
- **Undo:** undoing and redoing file operations is safer, and always acts on the exact file you meant.
- **Setup:** reinstalling and updating are safer, and setup only ever touches its own files.

## Full release notes

### Boxes Above Windows

* Fixed icons not being draggable into apps, between boxes and onto the desktop while boxes are above windows
* Fixed the hot corner triggering from a neighboring monitor

### Boxes and Icons

* Added smooth motion: dropped icons glide into place, new icons fade in, and the icons left in a box close the gap
* Added a Windows 11-style rename field that follows Windows' name length limit and cleans up pasted text
* Fixed right-dragging a selection rectangle inside a box not selecting icons
* Fixed two hard links to the same file showing as one icon

### Desktop Pages

* Added Desktop pages, with keyboard, mouse wheel, touchpad, middle-button and edge-hold switching
* Added creating, renaming and deleting pages from the desktop menu and **Settings › Desktop pages**
* Added **Move to page** for icons and boxes, which respects locks
* Added search across all pages, including folder boxes on other pages
* Fixed **Use for all boxes** and the icon view setting not reaching boxes on other pages
* Fixed the first file on an empty desktop not going to the chosen page
* Fixed short, fast touchpad swipes not always changing pages

### Folder Boxes

* Fixed opening a folder that two folder boxes show navigating both boxes
* Fixed folder boxes still watching folders you had left

### Layout

* Fixed a layout saved by a newer version being overwritten
* Fixed a failed daily backup replacing a good one
* Fixed a brief failure to read the desktop clearing box assignments
* Fixed desktop icons not coming back when graphics recovery failed after Explorer restarted

### Menus

* Fixed **Turn on Deskboxes** appearing only under **Show more options** in the Windows 11 desktop menu
* Fixed context menus not working after Deskboxes was turned off and on again

### Performance

* Improved start at sign-in: the wallpaper loads alongside everything else, and Deskboxes appears only once its first frame is ready
* Improved the first scan by creating thumbnails and folder previews in parallel (1.8 s instead of 4.7 s for 1,000 items)
* Improved moving and resizing boxes, switching pages, saving the layout, drawing large boxes and opening the desktop menu with many icons
* Fixed images that are no longer used staying in memory

### Settings

* Changed page changes to use the same motion as Windows Settings
* Changed the feature clips to Windows' motion curves, encoded to play on more PCs
* Fixed feature pages flashing black before their clip started

### Setup and Updates

* Fixed reinstalling over an existing installation when the folder path is spelled differently
* Fixed setup removing or closing anything other than its own files and programs
* Fixed an interrupted upgrade leaving a partly overwritten installation
* Fixed a failed update download discarding an installer that was already downloaded and checked

### Sorting Rules

* Fixed a sorting rule that targets a folder box blocking later rules

### Undo

* Fixed undoing a copy, or redoing a delete, recycling a different file that had since taken the same name
* Fixed undoing a delete not restoring the exact version that was deleted
* Fixed an undo that failed completely enabling redo
* Fixed quick successive file commands updating the wrong history entry
* Fixed undoing a deletion made on another page putting the icon on the current page
* Fixed undoing a layout change hiding files that arrived after it

### Known issues

* Deskboxes shows boxes on the main monitor only.
