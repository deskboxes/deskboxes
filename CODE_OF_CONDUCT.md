# Code of conduct

Deskboxes follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks are not tolerated in issues, discussions, pull requests or anywhere else in this project's spaces.

To report unacceptable behavior, contact the maintainer through a [private security advisory](https://github.com/deskboxes/deskboxes/security/advisories/new) (it is private, and not only for security issues), or use GitHub's **Report content** option on the comment. Reports are handled confidentially.
